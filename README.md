# Dubai Street Baron | Banknote Conservation & Chemical Solutions

Professional banknote conservation platform, specialist ultrasonic cleaning equipment, and certified chemical formulations.

Built with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide React**.

---

## 🏛️ Features & Architecture

- **Brand & Heritage**: Genuine banknote conservation, anti-breeze dye removal, and specimen calibration for Asian and GCC financial institutions and private collections.
- **Equipment & Solutions**:
  - Automated & Ultrasonic Multi-Tranche Cleaning Machinery (DSB-800).
  - High-purity SSD Universal Chemical Solutions & Activation Powders.
  - Industrial-grade Caluanie Muelear Oxidize.
  - Genuine Asian & GCC currency calibration specimens (SAR, SGD, AED).
- **Interactive Tools**:
  - Banknote Conservation & Cleaning Estimator configured for Asian and GCC currencies.
  - Direct WhatsApp support desk integration with pre-filled technical inquiry messages.
- **Mobile First**:
  - Responsive frosted glass left drawer navigation.
  - Photography-first compact hero slider.

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

View in your browser at: **`http://localhost:3000`**
